Un petit projet Python qui dessine un quartier d'immeubles généré aléatoirement avec `turtle`. À chaque lancement, le quartier, la météo et les détails changent : aucun rendu n'est identique.
 
## Fonctionnalités
 
- Immeubles aléatoires : de 1 à 4 étages, couleurs de façade et de toit tirées au hasard
- Portes : 2 modèles (rectangulaire ou arrondie), placées sur l'un des 3 emplacements du rez-de-chaussée
- Fenêtres : rondes ou carrées
- Balcons : 1 chance sur 4 par fenêtre d'avoir un balcon avec rambarde
- Toits : pointu, arrondi, ou pointu avec cheminée
- Météo aléatoire : soleil, nuageux, pluie ou nuit (étoiles et lune)
- Route dessinée sous les immeubles
